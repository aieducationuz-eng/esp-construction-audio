# ESP for Construction Engineers – audio

Audio for the Rise courses *ESP for Construction Engineers* (Modules 1–4) by Odilbek Kattaev.

- `audio/MxLy-listening.mp3` – listening dialogues (two voices)
- `audio/MxLy-model.mp3` – model answers for the speaking tasks
- `audio/MxLy-reading.mp3` – reading texts read aloud

Voices: Kokoro-82M neural text-to-speech (Apache-2.0), British English voices.
All names, companies and figures in the dialogues are fictional.
Served to the courses through jsDelivr: `https://cdn.jsdelivr.net/gh/aieducationuz-eng/esp-construction-audio@main/audio/<file>`
